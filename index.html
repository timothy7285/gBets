Comprehensive Architecture & Handbook Guide

gBet Greyhound Race Predictor

An advanced quantitative handicapping and race analysis platform designed to automate multi-variable modeling, live market sentiment analysis, granular database storage, and complete Return on Investment (ROI) tracking.

🧭 Navigation, Quick-Jump & Interactive Overlays

⚡ Quick-Jump Ribbon & Menu

Accordion-style vertical sidebar grouping meetings by track and date. Offers instant one-click navigation to streamline workflows and optimize screen space.

🟢 Live Status Indicator Legend

Real-time indicators (Computed 🟢, Settled 🎯, Neutral ⚪) provide immediate feedback on race states.

🎟 Modals & Overlay Interfaces

Pop-up overlay sheets (such as the Saved Prediction Inspector) let you review deep historical breakdowns and model weight configurations without losing context.

🗂️ Functional Tabs & Workflow Modules

📁 Race Details Tab

Import official race information via .txt files or the 1-click TABtouch clipboard tool. Features active race selectors, rename options, and result synchronization.

📊 Dog Statistics Tab

Extensive performance repository supporting CSV bulk imports (from The Print Hub), manual run/trial drawers, inline editing, deletion, and search filters.

⚡ Meeting Summary Dashboard

Concise batch overview card grid displaying top picks, distances, and confidence ratings sorted alphabetically by track and ascending race number.

📈 Analysis & Predictions

Dynamic handicapping hub featuring model weight customizers, sprint/distance presets, Softmax probability distribution meters, and runner form metrics.

🎯 Saved Predictions & ROI

Stores past analyses, actual podium placers, and payouts. Calculates automated win, place, and combined strike rates alongside financial ROI performance.

⚙️ Settings & Database Tab

Houses live file system disk syncing, JSON manual USB snapshots, browser storage health estimation, and selective data maintenance tools.

💾 Robust Database Architecture & Exports/Imports

The application leverages a high-performance IndexedDB storage architecture coupled with direct File System Access API streaming, ensuring rapid entity retrieval and zero data loss.

📥 Flexible Multi-Format Import

Seamlessly ingest race card details via standard .txt files or TABtouch clipboard buffers, historical dog performance records via bulk .csv sheets, and historical backups via .json snapshots.

📤 Intuitive Data Export

Export complete historical prediction datasets, betting performance logs into structured CSV spreadsheets, or portable JSON database snapshots for cross-device USB transport.

🔬 Advanced Predictive Models & Handicapping Workflow

  • Chronological Form Decay: Continuous time-based weighting system (~28-day half-life) prioritizing recent runner fitness and filtering mismatched distances.
  • Fluke Mitigation & Outlier Filtering: Automatically isolates ceiling anomalies and distorted trial runs to evaluate reliable median capability.
  • Track & Distance Variant Normalization: Converts raw race times into standardized differential figures relative to venue medians.
  • Traffic & Bump Modeling: Evaluates adjacent box early speeds to calculate traffic risks for slower runners drawn outside fast pacers.
  • Softmax Probability Calibration: Passes composite numerical scores through a power curve function for market-aligned win distributions.

📐 Mathematical Scoring Formula

Lower final composite scores indicate superior predicted performance and win probability:

Score = (WinDiv × W1) + (VariantBestTime × W2) + (VariantAvgTime × W3) + (Best 1Sec × W4) + (Avg 1Sec × W5) + (EarlyPos × W6) - (ClosingGain × W7) - (DynamicBoxBonus × W8) + TrafficPenalty - RecencyAdjustment
